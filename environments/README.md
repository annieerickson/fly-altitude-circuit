# Environment specifications

Use  `altitude-env` for all
non-connectomics workflows. It is specified in the root
`environment.yml`.


| Dataset | Environment name | Specification |
| --- | --- | --- |
| FAFB | FAFB-connectome-env | [FAFB_environment.yml](FAFB_environment.yml) |
| MANC | MANC-connectome-env | [MANC_environment.yml](MANC_environment.yml) |


To retrieve data from the connectomic source rather than the provided cached datasets, please use each respective environment.
